## What This Is

Urban Threads is a fictional Indian clothing brand prototype, built as a single-page
application using vanilla HTML, CSS and JavaScript. It was generated by the
Demo-Builder agent during the bridge-demo stage and placed here for PM review.

**All data is fictional. All contact details are illustrative. Nothing is submitted,
stored or communicated to any server.**

---

## How to Open

1. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge).
2. No build step, no server, no install required.
3. For mobile layout testing: open DevTools → Toggle device toolbar → 390 px width.

```
projects/urban-threads/
├── index.html   ← Open this
├── styles.css   ← Linked by index.html
├── app.js       ← Linked by index.html
└── README.md    ← This file
```

## Features

| Feature | How to test |
|---------|-------------|
| Responsive homepage | Open index.html; resize from 1440px to 390px |
| Marquee banner | Visible below hero on homepage |
| Category tiles | Click Womenswear / Menswear / Indian wear / Unisex |
| Product catalogue | Navigate to Shop (top nav) |
| Gender filter chips | Click Women / Men / Unisex / Indian wear in Shop |

| Price range slider | Drag slider in Shop sidebar |

| Size selection (quick view) | Click size buttons in quick view modal |
| Modal close — button | Click × button in modal |
| Modal close — overlay | Click outside the modal panel |
| Modal close — keyboard | Press Escape |
| Modal focus trap | Tab through modal — focus stays inside |
| Demo login | Navigate to Sign in; enter any email + password |
| Demo credentials shown | Shown at bottom of Sign in form |
| Password show/hide | Click "Show" button in password field |

| Contact FAQ accordion | Click each question to expand/collapse |
| Footer nav links | All link to relevant pages |
| Mobile hamburger menu | At ≤760 px, hamburger appears; tap to open |
| Mobile filter toggle | At ≤960 px, "Filters" button appears |

## Known Limitations

See [`docs/test-results.md`](docs/test-results.md) for the full test log.

| Item | Detail |
|------|--------|
| No persistence | All admin changes (add/edit/delete) reset on page refresh |
| No real cart | "Enquire about this piece" links to the contact page |
| No payment flow | Not applicable for a prototype |
| No authentication | Sign-in is visual only; no token or session is created |
| No backend | 100% client-side; no network requests |
| No images | Product visuals use SVG garment illustrations |
| Google Fonts CDN | Fraunces + Inter load from fonts.googleapis.com; works offline with system font fallback |
